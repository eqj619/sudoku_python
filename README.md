## 高速化（ビットマスク + MRV）

ソルバーを書き換え、テストケース全体で約27倍高速になりました。CLI の使い方と出力は変わりません。

### 変更内容

- **盤面**：セルごとのオブジェクト（`aslot`）をやめ、81要素のフラットな配列にしました（0 = 空き、1〜9 = 確定値）。
- **候補の表し方**：行・列・3x3ボックスごとに、使用済みの数字を9ビットの整数で管理します。空きセルの候補は `ALL & ~(rows[r] | cols[c] | boxes[b])` の1回の計算で求まります。数字を置いたり戻したりするたびにこのマスクを更新するので、盤面全体を走査し直す必要がありません。
- **事前計算テーブル**：`BITCOUNT`（候補の数）と `DIGITS`（候補の数字リスト）を512通りすべてのマスクについて起動時に作っておき、表引き1回で求めます。
- **探索**：毎回、候補が最も少ない空きセルを選んで試します（MRV）。候補が0個のセルが見つかれば即座に戻り、候補が1個のセルがあれば最優先で埋めます。
- **巻き戻し**：試行ごとに盤面全体（81セル）をコピーして復元するのをやめ、1セル単位で置いたり戻したりします。
